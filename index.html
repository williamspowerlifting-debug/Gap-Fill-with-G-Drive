/** * Cloudflare Worker — gapfill-ai-v2 * Deploy to: https://gapfill-ai-v2.williamspowerlifting.workers.dev * * ─── Required Cloudflare Secrets (set via dashboard or wrangler secret put) ─── * BUNNY_API_KEY — Bunny.net Video API key * BUNNY_LIBRARY_ID — Bunny.net Stream library ID (numeric string) * BUNNY_CDN_HOST — CDN pull-zone hostname, e.g. vz-abc123.b-cdn.net * ASSEMBLY_AI_KEY — AssemblyAI API key (https://www.assemblyai.com) * OPENROUTER_KEY — OpenRouter API key (used for /generate-gaps and /generate-summary) * * ─── Endpoints ─────────────────────────────────────────────────────────────── * POST /create-bunny-video Create a new Bunny Stream video slot * PUT /upload-bunny-chunk Stream-upload the video file to Bunny * GET /bunny-status Poll Bunny transcoding progress * POST /transcribe Submit audio/video URL to AssemblyAI * GET /transcribe-status Poll AssemblyAI for transcript result * POST /generate-gaps AI gap selection at a given CEFR level * POST /generate-summary NEW — AI summary for summary gap-fill mode * POST /save-lesson Store lesson JSON in KV, returns { id } * GET /load-lesson?id=... const res = await fetch("https://openrouter.ai/api/v1/chat/completions", { method: "POST", headers: { Authorization: "Bearer " + env.OPENROUTER_KEY, "Content-Type": "application/json", }, body: JSON.stringify({ model: "openai/gpt-4o-mini", messages: [{ role: "user", content: prompt }], temperature: 0.4, }), }); if (!res.ok) { const e = await res.json().catch(() => ({})); return err("OpenRouter summary failed: " + (e.error?.message || res.status)); } const data = await res.json(); const summary = data.choices[0].message.content.trim(); return ok({ id, shareUrl }); } // ════════════════════════════════════════════════════ // GET /load-lesson?id=... // Returns: lesson JSON object, or 404 if not found // ════════════════════════════════════════════════════ if (path === "/load-lesson" && request.method === "GET") { if (!env.LESSONS) return err("KV namespace LESSONS not bound", 500);
